# learning_CF
이 github repository는 Cell Formation문제를 푸는 MILP solvers를 가속하기 위해 분리자를 학습하는 Branch-and_Cut 알고리즘을 구현하기 위한 data와 코드를 제공한다.
알고리즘과 파이썬 코드는 다음 논문으로부터 채용하여 구현하였다.
Li, S.,	Ouyang,	W., Paulus,M., Wu, C. (2023). Learning to Configure Separators in Branch-and-Cut.
Advances in Neural Information Processing Systems (NeurIPS) 36,	pp.60021‒60034.
